# 3D-Printed Enclosure

This directory contains the 3D-printable enclosure used by the ESP32-C3 Elegoo Centauri Carbon 2 Monitor.

The enclosure is a modified/remixed version of DorffMeister's ([@DorffMeister_7295](https://www.printables.com/@DorffMeister_7295)) Printables model [Case for 2.8 ILI9341 TFT LCD and Microcontroller](https://www.printables.com/model/441958-case-for-28-ili9341-tft-lcd-and-microcontroller). The project-specific remix is published as [Case for 2.8 ILI9341 TFT LCD and ESP32-C3](https://www.printables.com/model/1822402-case-for-28-ili9341-tft-lcd-and-esp32-c3).

The project adaptation includes:

- a revised front bezel that better hides the rough or uneven edges of the ILI9341 module;
- a USB cut-out;
- an ESP32-C3 mounting solution.

The desktop holder/platform was already part of DorffMeister's original design and is not a modification made by this project.
